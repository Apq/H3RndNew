# 真随机开局

英雄无敌3 HD Mod 插件，提供开局真随机、全局真随机和宝屋最大化：

1. 主菜单「新游戏 → 单人场景」的选图界面增加「开局真随机」复选框。勾上后，这场新游戏开局每次取随机数都向系统要一个新数；不勾则仍用原版伪随机。
2. 游戏内随时按热键（默认 F11）打开设置窗，可开「全局真随机」——游戏全程（含战斗等）随机数都换成系统级随机；还可调日志等级、修改热键本身。
3. 单人场景选图界面胜利条件标题右侧增加「宝屋最大化」、比例滑块和百分比。新档生成成功后，按比例只提升宝箱、11种宝屋、资源堆和营火的奖励，宝屋守军保持原版结果；海上宝箱（海箱）不处理。所有新增宝物遵守地图宝物限制。

开局档只影响单人场景点「开始」之后的开局：固定场景换这场档案，随机地图连人数和地图布局一起换。多人、战役、教程、读取旧档、已经在打的游戏和战斗都不改。全局档才覆盖战斗等全程取数；联机锁定回合时不要开全局档。

目标版本是 Shadow of Death（`SOD = 0xFFFFE403`），仅 x86。

## 行为

### 开局真随机（选图界面复选框）

- 复选框在「显示可选场景」右侧，第一次打开默认勾上。
- 点一下即切换，当时写入 `H3RndNew.user.ini`，下次启动恢复。
- 勾上：开局期间游戏 `Rand` 和随机图直接调用的 `_rand` 都改为系统随机数。
- 不勾：这两处走原版伪随机公式。
- 系统随机数取不到的那一次退回原版，不用时间补。

### 宝屋最大化（选图界面）

- 胜利条件标题右侧显示复选框、100px 自绘水平轨道和百分比；默认不勾、默认 100%。点击或拖动轨道直接按位置选择比例，无预设百分比档位，显示到 0.1%。勾选和比例当时写入用户配置，重新启动恢复。
- 比例是每个独立对象被处理的概率：0% 不处理，100% 选中全部符合条件对象，中间值允许单局数量波动。
- 只在原版单人新档成功生成后处理。陆箱取 2000 金币/1500 经验；海箱不处理（2026-10-12 用户裁定排除）；11 种宝屋取运行时第 4 档奖励，守军保持原样；资源堆和营火提升至普通上限，已有更高数量保留。
- 新宝物统一遵守地图允许表、全局禁用、目标等级和工作池。指定等级工作池耗尽会重置该等级的可用池；地图或全局禁用使该等级全无合法候选时保留原奖励。

### 设置窗（游戏内热键，默认 F11）

- 冒险地图、战斗、主菜单按热键都能打开；选图等 H3 自己的模态界面里暂不保证。
- 窗里三样：日志等级下拉框、全局真随机复选框（默认不勾）和热键修改。
- 日志等级下拉五级：trace/debug/info/warn/error，点选立即生效并写入 user.ini；ESC、回车、点空白处只收起不改动。默认 info。
- 点「全局真随机」即切换并立即写入 user.ini；开启后全程 `Rand` / `_rand` 都走系统级随机（开局复选框此时被全局档覆盖）。
- 点键名（如 `F11`）进入侦听，按一个新键即生效（ESC 取消）；修饰键单独按不生效。改完即写入 user.ini。
- F12 已被 SoD_SP 插件的设置占用，别选。
- 热键存的是键盘扫描码（=游戏内部键码），默认 87=F11。

玩家能看到的完整行为见 [需求文档.md](docs/需求文档.md)，接入点和取数替换见 [设计文档.md](docs/设计文档.md)；「宝屋最大化」的完整档位和实现边界见 [宝屋最大化设计文档.md](docs/宝屋最大化设计文档.md)。「仓库」功能的纯逻辑 `WarehouseCore`、v1 附件 `WarehouseCodec`、事务策略层 `WarehouseStore` 与原生适配层 `WarehouseStore.inc.cpp`（SaveGame/LoadGame 后置 Hook、实际路径捕获、zlib 边界读取器、原子写回、新局清空）已完成离线测试与真实 patcher ABI 回归；游戏内背包 UI 尚未实现，游戏内存档行为待用户验收，详见[仓库设计文档.md](docs/仓库设计文档.md)。

## 部署

```text
<游戏目录>\_HD3_Data\Packs\热血插件\
```

目录里放：

```text
H3RndNew.dll
H3RndNew.default.ini
使用说明.txt
```

`deploy.ps1` 从仓库根 `H3Env.ps1` 读取当前游戏目录（当前为 `D:\Heroes3\Heroes3_2026.10.09`），把这三个文件复制到 `<游戏目录>\_HD3_Data\Packs\热血插件`。然后在 HD Mod 启动器的插件页，把包含本 DLL 的「热血插件」加到已加载。临时目录可用环境变量 `H3_GAME_DIR` 覆盖。

## 构建

在本目录执行：

```text
build.bat
```

它用 Visual Studio 2026 的 MSBuild 做 Release|Win32 全量 Rebuild。产物是 `Release\H3RndNew.dll`。编译依赖仓库里的 `H3API\single_header`，不另带一份头文件。在 CMD 中先设置 `set "H3RND_RUN_AUDIT_TESTS=1"` 和 `set "H3RND_PATCHER_DLL=<游戏目录>\patcher_x86.dll"`，再运行 `build.bat`，会额外编译并运行不启动游戏的随机审计、真实 patcher ABI、仓库 Core/Codec 独立测试。连续命令须用引号赋值，避免 `set VAR=1 &&` 把尾随空格写入值而跳过测试。仓库金样另可运行 `python tests/warehouse_golden.py --check` 验证。

## 打包

在本目录执行：

```text
pack.bat
```

它把 `Release\H3RndNew.dll`、源目录配置和说明打成 `Release\真随机开局_vX.Y.zip`，版本号取自 `H3RndNew.rc` 的 `FileVersion` 前两段。包内带 `热血插件\` 前缀目录，解压到游戏 `Packs` 即装。运行日志（`*.log`）和玩家配置 `H3RndNew.user.ini` 自动排除。成功后窗口默认直接关闭，要看结果先 `set PAUSE_ON_SUCCESS=1 && pack.bat`。

## 配置

`H3RndNew.default.ini` 是出厂默认，升级会被覆盖。玩家改动写在同目录的 `H3RndNew.user.ini`，没有这个文件也能跑。

```ini
[General]
TrueRandom=1
TrueRandomFull=0
SettingsHotkeyScan=87

[BankMaximize]
Enabled=0
Ratio=1000

[Logging]
DisableLog=0
MinLevel=info
```

`TrueRandom` 是界面没有读到玩家配置时的出厂勾选，`0` 不勾，`1` 勾上。`TrueRandomFull` 是全局真随机（设置窗里切换，`1` 全程替换）。`BankMaximize.Enabled` 控制宝屋最大化复选框的默认状态，`0` 不启用、`1` 启用；`BankMaximize.Ratio` 是 0..1000 的千分比，1000 表示 100%，缺失或越界值会被限制到有效范围。两项都在选图界面改动时写入 `H3RndNew.user.ini`。`SettingsHotkeyScan` 是设置窗热键的扫描码（默认 87=F11；F1..F10=59..68，A..Z=30..55，F12=88 勿用）。后两项在游戏内设置窗里改过之后以 user 层为准，不要手改 default。

日志写在插件自己的目录，文件名是 `H3RndNew_日期_时间.log`。`DisableLog=1` 完全不写。`MinLevel` 可选 `trace`、`debug`、`info`、`warn`、`error`。运行期间的 `RNG审计[…]` 行按入口分类汇总全部随机调用（真随机/原版路径/失败回退等）。Info 保留关键边界快照及有调用时每 5 分钟的心跳，Debug 每 30 秒最多一组心跳、只列关键控件，完整控件清单留给 Trace；未启用且无历史数据的全局空统计省略。Hook 链首次/变化详情和故障诊断仍保留。读法与复测步骤见 `使用说明.txt`。
