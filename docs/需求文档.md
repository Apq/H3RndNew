# 开局真随机需求

创建新游戏、从地图生成游戏档案时，原版只有伪随机。本插件提供三项功能：一，「新游戏 → 单人场景」的选图界面加「开局真随机」复选框（开局档）；二，游戏内按热键打开设置窗，提供「全局真随机」开关、日志等级调整和热键修改（全局档）；三，在单人选图界面提供「宝屋最大化」复选框和比例滑块，成功建档后按比例提升指定对象的奖励。

本文只写要对玩家成立的行为。按钮位置怎么量、勾选状态怎么存、随机源怎么换，留到设计文档。

## 界面（开局档：选图界面复选框）

主菜单点「新游戏」，再点「单人场景」，之后出现的选图界面上，「显示可选场景」按钮的右侧，增加一个复选框，文字是「开局真随机」。

- 勾上：这次开局用真随机。
- 不勾：这次开局用原版伪随机。
- 第一次打开这个界面时，复选框是勾上的。
- 它跟「显示可选场景」同一行，紧挨在按钮右边，不挡住按钮，也不改按钮原来的功能。
- 点复选框本身即可切换勾选，不需要另开窗口，也不需要点「确定」才生效。
- 复选框只出现在这条路径上：主菜单「新游戏」→「单人场景」→ 选图界面。
- 「新游戏」里的多人游戏、战役、教程，点进去之后的界面上没有它。
- 主菜单「读取游戏」之后的界面、战略地图和战斗里也没有它。
- 从单人选图界面返回后再进多人、战役或教程，复选框不得留下来。

## 宝屋最大化（单人新游戏选图界面）

同一单人场景选图界面的胜利条件标题右侧增加「宝屋最大化」复选框、水平比例滑块和百分比。复选框默认不勾，滑块默认 100%，比例按 0.1% 显示并保存到 `H3RndNew.user.ini` 的 `[BankMaximize]` 节。

勾选后，仅在原版新档生成成功返回后按比例处理地上/地下宝箱、海上宝箱、11 种宝屋、资源堆和营火。处理只改奖励：宝屋守军、守军分堆和升级结果保持原版生成结果。陆上宝箱最大化取 2000 金币/1500 经验档；海上宝箱最大化取 level 2（1000 金币＋一件 Treasure 级宝物）。资源堆和营火提升到普通上限，地图作者已经写入的更高数量保留。

所有新增宝物都遵守地图宝物允许表、全局禁用状态、目标等级和本局宝物池；本局某等级工作池耗尽时按原版规则重置该等级可用池，地图或全局禁用使该等级没有合法候选时保留原奖励，不跨等级强塞。读档、保存、取消、生成失败、多人、战役、教程和已经开始的游戏不处理。完整档位和边界见 [宝屋最大化设计文档.md](宝屋最大化设计文档.md)。

## 记住选择（开局档）

勾或不勾，在玩家改动的当时写入玩家配置。关掉游戏再开，选图界面恢复上次的勾选状态。

没有读到玩家配置时（第一次使用，或配置被删掉），按勾上处理。出厂默认也是勾上。

## 设置窗（全局档）

游戏内随时按热键打开设置窗，默认热键 F11，可在窗内修改。

- 热键在主菜单、冒险地图、战斗中都能开窗；与 SoD_SP 的 F12 不冲突（本插件默认 F11）。
- 窗内三样：日志等级下拉、全局真随机复选框、热键修改；以及一个「确定」关闭。
- 日志等级下拉五级：trace/debug/info/warn/error。点选立即生效并写入玩家配置；ESC、回车或点空白处只收起，不改动。默认 info。
- 「全局真随机」默认不勾。勾上：游戏全程随机数（含战斗、走动等）都走系统级随机。不勾：全程走原版伪随机，开局档行为独立保留。
- 全局勾上时，开局档被覆盖：开局与全程都是系统级随机。
- 点一下即切换并立即保存，重开游戏保持。
- 修改热键：点当前键名进入「请按新键…」，按一个新键生效，ESC 取消；单独按 Ctrl/Alt/Shift/Win 不响应；F12 因被 SoD_SP 占用不建议设置。
- 热键按一下弹窗、再按同键不叠加弹窗；设置窗内按键不漏进游戏。
- 窗口文案第一版只有中文。

## 生效范围

开局档只影响单人新游戏点「开始」之后、创建这场游戏时用的随机。选的是固定场景，就换这场档案的开局随机。选的是随机地图，地图怎么铺、以及随后这场档案的开局随机，都换。已经在打的游戏、读进来的旧档，不因这个勾选而改随机。多人游戏、战役、教程的开局也不走这个勾选。

全局档开启后，开局档的窗口限制不再存在：全程（走动、战斗、事件、寻宝……）随机都换系统级随机。联机锁定回合制下双方随机源不一致会导致不同步，玩家不应在联机时开全局档。

在单人选图界面勾上之后点「开始」，这场新游戏走真随机。取消勾选后再点「开始」，这场走原版伪随机，表现与未装本插件相同。

同一张固定地图、同样的难度和玩家设置，勾上时每次开出的局面应当不同；不勾时保持原版那种由种子决定的伪随机。随机地图同样：勾上时每次铺出的地图应当不同；不勾时保持原版由本地时间导出的那颗种子。

## 不做什么

- 不改「显示可选场景」按钮本身，也不改地图列表、难度、人数这些原有控件。
- 不在多人游戏、战役、教程、读取游戏里提供这个复选框。这几条路径即使和单人共用同一张选图版面，也不得把复选框画上去。
- 不改已经开始的游戏（开局档）；战斗随机只在全局档开启时才替换。
- 开局档不做单独的设置窗口，那个勾选就是设置；设置窗只服务全局档、热键与日志等级。
- 界面文字第一版只有中文。

## 验收

1. 主菜单「新游戏」→「单人场景」进入选图界面，「显示可选场景」右侧能看到「开局真随机」，且第一次是勾上的。
2. 点一下变为不勾，再点一下恢复勾上。点这个框不会打开或关掉场景列表。
3. 勾着点「开始」，开局走真随机；去掉勾再开一局，走原版伪随机。
4. 关掉游戏再走同一条路径进入，勾选状态与上次离开时一致。
5. 「新游戏」下的多人游戏、战役、教程，以及主菜单「读取游戏」，进去之后都看不到这个复选框。
6. 主菜单、冒险地图、战斗中各按一次 F11，都能弹出设置窗；窗内「全局真随机」默认不勾。
7. 勾上「全局真随机」后开局一局，日志显示全程替换；取消后恢复原版。
8. 点键名进入「请按新键…」，按 F9 后键名变 F9，关窗重开游戏后 F9 开窗、F11 不再开窗。
9. 侦听态按 ESC 取消，热键不变。
10. 设置窗开着时再按当前热键不弹第二个窗。
11. 点开日志等级下拉选 debug，日志立即变详细；关游戏重开仍保持 debug。ESC 和点空白处只收起，等级不变。
